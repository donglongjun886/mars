# Mars v0.1 设计

> 2026-10-27。决策均由作者做出，依据见 [../research/00-comparison.md](../research/00-comparison.md) 及四份单品调研。
> 本文档记录决策与范围，不写实现细节。

## 1. 定位

Mars 是一个 Python CLI coding agent。单用户（作者本人），终端优先，无其他用户承诺。

## 2. 五项关键决策

| # | 决策点 | 结论 | 主要依据 |
| --- | --- | --- | --- |
| 1 | 模型 | DeepSeek V4.1 Flash（API id：`deepseek-flash`），走 OpenAI 兼容协议，不做多协议兼容；模型 id / base_url / key 走 env 或 CLI 参数，不写死 | 官方 model card；JSONVue API 分析 |
| 2 | 架构基线 | pi 式极简内核：单事件驱动主循环 + 4 工具；**功能面极简，地基面极重** | pi、dsh、deer-flow 2.0、Claude Code 四方收敛 |
| 3 | 安全 | 基础权限校验内建（`before_tool_call` 口子 + 危险命令确认）；用户可编程 hooks 后置，口子预留 | pi（钩子外置审批）、dsh（fail-closed 原则） |
| 4 | system prompt | 极简拼装：一句话身份 + 各工具自带 guideline，按启用工具动态组装 | pi、dsh（persona 一句话） |
| 5 | 测试 | 单元测试（工具函数）+ faux provider 驱动主循环，不碰真实 API | pi（test.sh/faux provider）、dsh（mock 只挡昂贵边界） |

地基边界：「地基」仅指五样——事件模型、provider seam（供 faux provider 替换，非多模型抽象）、工具注册与调用、循环的中断与错误处理、会话持久化。地基之外皆为功能，功能从简实现，不为想象中的扩展提前抽象。

模型层备注：开启 thinking 模式——coding 任务的推理质量是核心，协议坑早踩比晚踩好；1M 上下文下 compaction 推后，但每次会话结束打印 token 用量与轮数；换模型 = 换配置重跑，跨模型成功率对比是 benchmark 阶段的素材。

协议约束（2026-11 按官方文档核实）：`deepseek-flash` = V4.1-Flash-1017，1M 上下文、384K 输出上限，thinking 默认开启（`reasoning_effort` 默认 `high`）。带 `tools` 的请求必须逐轮完整回传 `reasoning_content`，漏传即 400——会话日志必须持久化该字段，上下文重建时回填。流式 usage 没有独立 chunk，搭在最后一个 content chunk 上。thinking 模式下 `temperature`/`presence_penalty`/`frequency_penalty` 被忽略，`tool_choice` 不支持强制指定。前缀缓存自动生效，system prompt 与工具定义须保持字节稳定。

## 3. 技术栈

| 项 | 结论 | 理由 |
| --- | --- | --- |
| 运行时 / 包管理 | Python 3.14，uv（`requires-python = ">=3.13"`，`.python-version` 锁 3.14） | 系统自带 3.9 缺现代语法；uv 覆盖解释器、venv、lock、`uv run` |
| LLM 客户端 | `openai` 1.109.1，只允许出现在 `llm.py` | 官方 OpenAI 兼容；SDK 处理 SSE、分片 tool_call、usage |
| 并发 | 同步阻塞 + 生成器事件，不引 asyncio | v0.1 工具顺序执行；异步收益全在"不做"清单 |
| CLI 解析 | argparse | flag 少，零依赖 |
| 数据模型 | 事件用 frozen dataclass；消息与 JSONL entry 用 TypedDict + 显式 `from_dict`；工具 schema 用普通 dict | 无配置文件与外部结构化输入；不引 pydantic |
| 终端输出 | stdlib `print` + ANSI（按 `isatty()` 开关），不引 rich | 不做 TUI 美化；流式 delta 只需 flush |
| 测试 | pytest + pytest-cov；faux provider 为实现 `llm.py` client 接口的假类；`tmp_path` 隔离 | 只替换 LLM 层，下游用真实现 |
| 质量工具 | ruff（lint + format）+ mypy strict（仅 `src/`） | 单二进制；mypy 不需要 Node |
| 依赖预算 | 运行时仅 `openai`；开发 `pytest` `pytest-cov` `ruff` `mypy` | 其余一律标准库 |

## 4. 事件模型

术语见 [CONTEXT.md](../../CONTEXT.md)：turn 是用户输入到模型停止，step 是 turn 内一次模型请求加工具批次，event 瞬时、entry 持久。主循环只发事件；事件分两类——瞬时事件只给渲染，持久事件同时写 JSONL entry。

| 事件 | 持久 | 时机 / 载荷 |
| --- | --- | --- |
| `SessionStarted` | 是（session 头） | 新会话：session_id、cwd、model |
| `TurnStarted` | 否 | 一条用户输入进入循环：turn_id |
| `StepStarted` | 否 | 一次模型请求前：step |
| `ReasoningDelta` | 否 | thinking 增量：text |
| `TextDelta` | 否 | 正文增量：text |
| `ToolCallStarted` | 否 | 模型决定调用、执行前：call_id、name、arguments |
| `SessionFinished` | 否 | 会话收尾：total_usage、turns |
| `UserMessage` | 是（message） | 用户输入：text |
| `AssistantMessage` | 是（message） | 模型完成态：content、reasoning_content、tool_calls、interrupted |
| `ToolResult` | 是（tool_result） | 执行后：call_id、name、is_error、content、spill_path |
| `StepUsage` | 是（usage） | 每个 step 一条：prompt / completion / cache hit / cache miss / reasoning tokens |
| `TurnFinished` | 是（turn_end） | completed / max_steps / interrupted / error |

约定：

- 完成态单事件 + 独立 delta，不做消息三态；工具只有 start 与 result，无输出增量。
- delta 不落盘。持久事件由循环直接调 `session.append()` 写入，不依赖 UI 订阅者；事件流本身只给渲染与测试。
- 中断时已交付给用户的正文照常落为 `AssistantMessage`（`interrupted = true`）；一个字都未交付则不落。
- 循环是生成器（拉模型），调用方驱动；将来接 steering 只改循环内部。
- turn = 一条用户输入到模型停止；step = turn 内一次模型请求及其工具批次；步数上限按 turn 计。

## 5. v0.1 范围

**做**：

- CLI 多轮对话（最朴素的输入 + 流式打印，不做 TUI 美化）；配置面：`DEEPSEEK_API_KEY`、`MARS_MODEL` / `MARS_BASE_URL` / `MARS_MAX_STEPS`，CLI 另提供 `--model` / `--base-url` / `--max-steps` / `--resume`
- system prompt：身份句 `You are Mars, a coding agent working in the user's terminal.` + 环境块（cwd、日期、平台）+ 各工具 guideline + 两条通用规则（简洁；引用文件给完整路径）
- 加载项目指令文件 `AGENTS.md`（无则 `CLAUDE.md`）：从 cwd 向上找最近的 `.git` 作为仓库根（找不到就用 cwd），把根目录的文件作为单条快照进上下文；不做层级覆盖与懒加载
- 事件驱动主循环：循环只发事件，CLI 是事件的订阅者
- 4 个工具：`read` / `bash` / `edit` / `write`
  - `read(path, offset?, limit?)` 返回带行号的文本，默认最多 2000 行
  - `bash(command, timeout?)` 默认 120 秒、上限 600 秒
  - `write(path, content)` 自动建父目录；覆盖已有文件前必须读过
  - edit = 字面替换，支持一次多处编辑（`edits[]`，内存中顺序应用后原子写），任一 old 找不到或不唯一即整体失败，先读后写
  - 工具输出按行数+字节双限截断（2000 行 / 50KB，先到先截），截断时全文落盘到会话目录 `spill/` 并返回路径
  - 工具错误抛异常，由循环归一化为 isError 结果回灌
- JSONL 会话日志（id/parentId 树），上下文从日志派生；`--resume <id|latest>`，`--continue` 等价 latest；resume 后追加写同一文件；落盘 `~/.mars/sessions/<cwd-slug>/<YYYYMMDD-HHMMSS>-<6hex>.jsonl`
  - entry 五类：`session`（头，记 cwd / model / 版本）/ `message` / `tool_result` / `usage` / `turn_end`
  - assistant 消息必须持久化 `reasoning_content`（协议要求逐轮回传，漏传即 400）
- `before_tool_call` 口子 + 危险命令确认（`shlex` 拆 `&&` / `;` / `|` 后逐段字面前缀匹配固定清单，清单在 `policy.py`）；清单：`rm -rf`、`sudo`、`git push`、`git reset --hard`、`git clean`、`chmod 777`、`dd`、`mkfs`、`shutdown`、`reboot`，其余放行
- 失败与终止：429 / 5xx 退避重试 2 次；Ctrl-C 一次取消当前 step 并把已交付正文落盘（`interrupted = true`），两次直接退出
- 步数上限（默认 40）+ 优雅降级（撞限后发一次不带 tools 的收尾请求）
- 启动与交互：缺 `DEEPSEEK_API_KEY` 报错并以退出码 2 退出，不创建会话文件；REPL 单行输入，`/exit` 与 Ctrl-D 退出
- 会话结束打印 token 用量与轮数

**留口子不实现**：before_tool_call 策略注册机制（将来挂用户 hooks）；事件流的多订阅者（将来接 benchmark runner）。

**不做**（除非 dogfood 摩擦要求）：subagent、plan mode、compaction、steering 插话、MCP、插件系统、权限引擎、Web/GUI、多模型抽象。

## 6. 模块划分（骨架）

```
mars/
  __main__.py     # 入口
  cli.py          # CLI：订阅事件、渲染输出、读取输入
  loop.py         # 主循环：组装请求 → 调模型 → 执行工具 → 回灌，只发事件
  events.py       # 事件类型定义
  llm.py          # deepseek-flash 客户端（OpenAI 兼容，薄封装）
  tools/          # read / bash / edit / write，各自声明 schema + guideline
  session.py      # JSONL 日志读写、上下文派生、resume
  policy.py       # before_tool_call 口子 + 危险命令确认策略
tests/            # 单元 + faux provider 主循环测试
```

## 7. 完成标准

v0.1 完成的判定：用 Mars 完成一个真实的简单任务（例如让 Mars 修改自己的 README 并说明改动），全程无人工代写代码；会话可中断后 resume；结束后打印 token 用量。
